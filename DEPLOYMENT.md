# Deployment

This portfolio is a static site and does not require a build step.

## GitHub Pages

1. Open the repository settings.
2. Under **Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and the repository root.
4. Save the configuration and wait for the Pages workflow to finish.

## Pre-deployment check

Before publishing, verify the navigation on desktop and mobile, test external project/contact links, confirm the 404 page renders correctly, and review the browser console for errors.

The site files (`index.html`, `styles.css`, and `script.js`) can also be deployed directly to any static hosting provider.
