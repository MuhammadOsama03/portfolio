# Accessibility notes

The portfolio is designed to remain usable with keyboard navigation, reduced-motion preferences, and smaller screens.

## Review checklist

- Navigation controls expose their expanded state to assistive technology.
- The mobile menu can be closed with Escape and returns focus to its trigger.
- Page sections use semantic headings and descriptive link text.
- Interactive elements retain visible keyboard focus.
- Motion enhancements should respect `prefers-reduced-motion`.
- Layout and content should remain readable without horizontal scrolling on mobile.

These checks are part of the final pre-deployment review rather than one-time fixes.
