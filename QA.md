# Portfolio QA checklist

Use this short pass before a demo or deployment.

## Desktop

- Follow each navigation item and confirm the correct section receives focus/active context.
- Open every project and social link in the intended destination.
- Resize through common desktop widths and check that cards and text remain balanced.

## Mobile

- Open and close the navigation with the menu button.
- Close the menu with Escape and by selecting a navigation link.
- Rotate between portrait and landscape and check for horizontal overflow.
- Confirm buttons and links have comfortable touch targets.

## Content and browser checks

- Review spelling, project descriptions, role names, and contact information.
- Test the custom 404 page.
- Check for broken assets, console errors, and unexpected layout shifts.
- Verify the current year is rendered in the footer.
