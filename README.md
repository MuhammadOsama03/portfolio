# Portfolio

My personal portfolio website for presenting my software development, AI/ML, IoT and data work.

The site is being built in stages rather than as a one-day template project. The first stage establishes the responsive layout and the main sections. Project details, experience, links and final interactions will be refined in the next stages.

## Current structure

- Hero and navigation
- About
- Skills
- Selected projects
- Experience
- Contact
- Responsive mobile navigation

HTML, CSS and JavaScript.
