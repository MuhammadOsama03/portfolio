# Portfolio

My personal portfolio website for presenting my software development, AI/ML, IoT and data work.

## What it includes

- Responsive navigation and hero section
- Technical skills grouped by area
- Selected project cards with direct repository links
- Software, data, open-source QA and leadership experience
- Mobile-friendly layout
- Contact and GitHub navigation

## Featured work

### StudyLens RAG
A local PDF question-answering assistant built around semantic retrieval, ChromaDB and grounded Gemini responses with source citations.

### HIFAZAT
An IoT + AI project exploring sensor-based testing of drinking water, milk and cooking oil.

### Gemini CLI Agent
A Python command-line AI agent that uses Gemini function calling with calculator and web-search tools.

## Tech

HTML, CSS and JavaScript. The portfolio intentionally stays lightweight and does not require a frontend framework or build process.
